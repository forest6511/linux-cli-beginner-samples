## この章で学ぶこと

- 自分が誰で、どのグループに入っているかを確かめる（`whoami`・`id`・`groups`）
- `ls -l` の権限の欄を読む。権限を記号と数で変える（`chmod`）。新しいファイルの権限が決まるしくみ（`umask`）
- ファイルの所有者とグループを変える（`chown`・`chgrp`）
- 管理者として実行する（`sudo`）。`sudo` を付けてもリダイレクトでは書けない理由
- `Permission denied` が出たときに、原因を切り分ける

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch07 .
cd ch07
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 写したフォルダーを消し、上の手順でもう一度写します（手順は本の章の初めにあります）
