# 第12章 総合ハンズオン 作業メモのコマンドを作る（練習用のファイル）

書籍『エンジニアのためのLinux CLI入門』（第2版）第12章の練習用のファイルです。[トップのページに戻る](../../README.md)

本: [Kindle 版](https://www.amazon.co.jp/dp/B0GSSJHT2B)・[ペーパーバック](https://www.amazon.co.jp/dp/B0GSYM4YFW)

## この章で学ぶこと

- ここまでの章で学んだコマンドを組み合わせて、1つのコマンドを作る
- 作業メモを記録する・一覧を見る・探す・日ごとに数える・作業時間を合計する
- 作ったコマンドを、どこからでも名前だけで呼べるようにする

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch12 .
cd ch12
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 写したフォルダーを消し、上の手順でもう一度写します（手順は本の章の初めにあります）

## このフォルダーのファイル

- 使うファイル: [`memo-sample.txt`](memo-sample.txt)（2日分・4件の記録の見本）
- この章で作るファイル: `memo.sh`（完成したものはサンプルの `ch12/memo.sh`）・`~/.memo.txt`・`~/bin/memo`

このページ（README.md）は説明のためのもので、取り込んだサンプルには入りません。
