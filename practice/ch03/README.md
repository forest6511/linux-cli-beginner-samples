# 第3章 ファイルとディレクトリ（練習用のファイル）

書籍『エンジニアのためのLinux CLI入門』（第2版）第3章の練習用のファイルです。[トップのページに戻る](../../README.md)

本: [Kindle 版](https://www.amazon.co.jp/dp/B0GSSJHT2B)・[ペーパーバック](https://www.amazon.co.jp/dp/B0GSYM4YFW)

## この章で学ぶこと

- ディレクトリの木と、絶対パス・相対パスで場所を指す（`pwd`・`cd`・`ls`・`tree`）
- `ls -l` の結果を読む
- ファイルとディレクトリを作る・写す・動かす・消す（`mkdir`・`rmdir`・`touch`・`cp`・`mv`・`rm`）
- リンクを作り、ファイルの情報とパスの部分を取り出す（`ln`・`file`・`stat`・`basename`・`dirname`・`realpath`）
- ワイルドカード（`*`・`?`・`[ ]`）で、名前をまとめて指す

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch03 .
cd ch03
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 写したフォルダーを消し、上の手順でもう一度写します（手順は本の章の初めにあります）
