# 第2章 ターミナルとシェルの基本（練習用のファイル）

書籍『エンジニアのためのLinux CLI入門』（第2版）第2章の練習用のファイルです。[トップのページに戻る](../../README.md)

## この章で学ぶこと

- コマンドの形（コマンドの名前・オプション・引数）を知り、文字を表示する（`echo`・`printf`）
- 打ち間違えたときの `command not found` を読む
- 引用符（`'...'` と `"..."`）で、空白や記号をそのまま渡す
- コマンドの正体と使い方を調べる（`type`・`which`・`command -v`・`--help`・`man`・`help`）
- 打ったコマンドを呼び出し直す・止める・画面を消す・抜ける（↑・Tab・Ctrl ＋ R・Ctrl ＋ C・`history`・`clear`・`exit`）
- 使っている環境を調べる（`uname`・`hostname`）
- エディタ nano でファイルを開く・書く・保存する。vim に入ってしまったときに抜ける

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch02 .
cd ch02
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 写したフォルダーを消し、上の手順でもう一度写します（手順は本の章の初めにあります）
