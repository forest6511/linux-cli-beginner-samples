# 第11章 はじめてのスクリプト（練習用のファイル）

書籍『エンジニアのためのLinux CLI入門』（第2版）第11章の練習用のファイルです。[トップのページに戻る](../../README.md)

本: [Kindle 版](https://www.amazon.co.jp/dp/B0GSSJHT2B)・[ペーパーバック](https://www.amazon.co.jp/dp/B0GSYM4YFW)

## この章で学ぶこと

- コマンドを並べたファイル（シェルスクリプト）を作り、実行する（シバン・`chmod +x`・`./`・`bash`）
- 引数と入力を受け取る（`$1`・`$#`・`read`）
- 条件で処理を分ける（if・`test`・`[ ]`）、失敗したら止める（`>&2`・`exit 1`）
- 繰り返す（for・while・`seq`）
- 打ち間違えたときに、エラーメッセージから場所を見つけて直す
- 一時ファイルを使って、元のファイルを安全に置き換える（`mktemp`）
- 定期実行を登録する（`crontab`）

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch11 .
cd ch11
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 写したフォルダーを消し、上の手順でもう一度写します（手順は本の章の初めにあります）
