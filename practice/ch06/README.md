## この章で学ぶこと

- 文字列を含む行を探す（`grep`）。行の先頭・末尾を指す書き方（正規表現の入口）
- 列を切り出す（`cut`）、文字を置き換える（`tr`・`sed`）、列を選んで計算する（`awk`）
- 並べ替える（`sort`）、同じ行をまとめて数える（`uniq`）
- 2つのファイルを横につなぐ・共通の列で結合する・比べる（`paste`・`join`・`comm`）、列をそろえる（`column`）、文字を逆に並べる（`rev`）
- これらをパイプでつないで集計する

## このフォルダーの使い方

第1章で、サンプル全体を Ubuntu の中の `~/linux-study/samples` に取り込んであります。章の初めに、そこからこのフォルダーを写して使います（GitHub からダウンロードする必要はありません）。

```bash
cd ~/linux-study
cp -r samples/practice/ch06 .
cd ch06
```

このページを開くのは、次のようなときです。

- **ファイルの中身を確かめたいとき** … 下の一覧でファイルの名前を押すと、中身が表示されます
- **章を最初からやり直したいとき** … 本の章の初めにある、やり直すときの手順に従います。章によっては、フォルダーを写し直すほかに、変えた設定を元に戻す手順があります（第10章の `.bashrc`、第11章の定期実行など）

## このフォルダーのファイル

- 使うファイル
  - [`members.csv`](members.csv): 社員の一覧（id・名前・部署・都市）。1行目は見出しで、8人分
  - [`scores.txt`](scores.txt): 5人の名前と点数（空白で区切る）
  - [`report.txt`](report.txt): 作業の記録（5行）
  - [`fruits.txt`](fruits.txt): 果物の名前（同じ名前が何度も出る・7行）
  - [`list-a.txt`](list-a.txt)・[`list-b.txt`](list-b.txt): 果物の一覧（名前の順に並べてある）
  - [`depts.txt`](depts.txt): 部署の記号と部署名
- この章で作るファイル: `staff.txt` など
